# Module 13: Admission Odds Calculator Specs

## Algorithm Constraints
- Compares `student_profiles.gpa` against `universities.minimum_gpa` and `universities.acceptance_rate`.
- Standard calculation output categories: `'Reach'`, `'Match'`, or `'Safety'`.

## Views / Functions
- Computed on-the-fly inside Server Component or Server Action. No separate database write table required.
